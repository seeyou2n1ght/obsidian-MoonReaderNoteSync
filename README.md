# MoonReader Note Sync for Obsidian

这是一个 Obsidian 插件，用于通过 WebDAV 协议同步、解析并将静读天下（Moon+ Reader）的阅读高亮与笔记（.an 二进制文件）导入到本地 Vault 库中。

## 核心特性

* 增量数据同步：通过 PROPFIND 请求对比 WebDAV 元数据，仅下载并解析产生新笔记的书籍文件，降低网络和内存开销。
* 本地安全存储：使用 AES-256 算法加密 WebDAV 账户密码，加密密钥存储在当前 Vault 路径之外的本地安全目录。
* 离线缓存降级：在网络故障或服务器不可达时，自动读取本地历史缓存数据，维持数据导入的连续性。
* 结构化解析引擎：集成解压库将二进制文件解压，按照 17 行固定区块定位提取书籍元数据、高亮文本及个人批注。
* 可视化模板配置：提供直观的拖拽式 UI 编辑器，支持通过占位变量进行排版并在界面中实时预览渲染的文本。

## 安装指南

1. 下载最新版本的压缩包 moonreader-note-sync.zip 或获取 main.js、manifest.json 与 styles.css 文件。
2. 在本地 Vault 的插件存放路径下创建 moonreader-note-sync 目录，并将解压后的文件移入其中。
3. 打开 Obsidian 客户端，在第三方插件的系统设置面板中启用本插件。

## 配置说明

### 密钥与密码配置

1. 打开插件的专属设置面板。
2. 在安全配置区域中指定一个位于当前 Vault 路径之外的本地物理存储路径。
3. 点击生成密钥按钮，在指定路径下写入与当前设备绑定的 AES-256 密钥文件。

### WebDAV 连接配置

1. 在连接设置中填入指向静读天下备份缓存目录的 WebDAV 服务器端点地址。
2. 输入 WebDAV 账号的用户名与连接密码。
3. 确认输入，系统会自动调用本地密钥对密码进行加密并写入配置文件中。

### 笔记渲染配置

1. 定位到模板构建器的专属交互配置区域。
2. 将左侧显示的可选字段拖拽至右侧的文本模板编辑区进行排版设计。
3. 在下方的预览区域实时查看由变量解析出来的 Markdown 最终渲染效果。

## 使用方法

1. 点击 Obsidian 左侧边栏的同步操作图标，或在系统命令面板中执行 Sync Notes 关联指令。
2. 系统在执行完增量同步比对后，会自动弹出可供检索的书籍列表面板。
3. 搜索并选择目标书籍后按下回车键，对应的格式化笔记将直接插入至当前编辑器的光标位置。

## 模板变量定义

| 占位变量 | 属性描述 |
| :--- | :--- |
| {bookName} | 书籍名称 |
| {chapter} | 章节名称或索引数字 |
| {highlightText} | 划线高亮文本内容 |
| {note} | 用户输入的个人批注 |
| {color} | 十六进制高亮颜色代码 |
| {timestamp} | 物理生成时间戳 |
| {id} | 笔记条目唯一标识符 |
