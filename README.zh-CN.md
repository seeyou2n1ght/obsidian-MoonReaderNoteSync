# MoonReader Note Sync

[English](README.md) | 中文

将静读天下（Moon+ Reader）WebDAV 备份中的高亮和批注导入 Obsidian，支持搜索书籍、预览笔记、自定义模板和离线浏览缓存。界面随 Obsidian 显示中文或英文。

需要 **Obsidian 1.13.0 或更新的桌面版本**，不支持移动端。版本变化见[更新记录](CHANGELOG.md)。

## 安装

### Obsidian 插件市场

1. 打开“设置 → 社区插件”，按需开启社区插件功能。
2. 点击“浏览”，搜索 **MoonReader Note Sync**。
3. 点击“安装”，然后“启用”。

后续可在社区插件设置中“检查更新”。

### 手动下载构建产物

1. 打开 [GitHub 最新发布](https://github.com/seeyou2n1ght/obsidian-MoonReaderNoteSync/releases/latest)，从 **Assets** 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 将三个文件直接放入笔记库的 `.obsidian/plugins/obsidian-moonreader-sync/`，目录不存在时自行创建。
3. 重启 Obsidian 或重新加载插件，在“设置 → 社区插件”中启用。

源码压缩包不是构建后的插件。更新时只替换上述三个文件，保留 `data.json` 和缓存文件，避免重复安装。

## 使用

### 连接备份

先在静读天下中将阅读批注备份到 WebDAV，找到包含 `.an` 文件的目录。

1. 在插件设置中填写“WebDAV 目录地址”和“账号”。
2. 从“已保存的 Keychain”选择条目，或点击“新建 Keychain”填写名称及密码或应用密码。
3. 可先“测试连接”，测试不会保存。点击“验证并保存连接”应用配置；新建条目时点击“创建 Keychain 并保存连接”。
4. 打开侧栏的书库按钮，或执行“浏览和导入笔记”命令。没有缓存时自动获取书籍，之后点击“刷新书库”更新。

Keychain 名称支持小写字母、数字和连字符，最多 64 字符，已有名称不会被覆盖。更换账号或服务器后需重新选择凭据。已有条目在 Obsidian Keychain 中管理。

连接检查超过 30 秒会提示超时，也可取消。关闭设置会丢弃草稿并取消尚未开始写入的保存；已经开始写入时，保存及书库连接切换会继续完成。

### 导入笔记

选择书籍后预览前 3 条批注，导入按钮写入该书的**全部批注**。底部显示目标笔记和写入位置。

- 默认插入打开面板时记录的光标位置，不替换选中文本。焦点在其他面板时，使用仍打开的最近 Markdown 笔记。
- 没有打开的目标时，点击“选择笔记”，选中文件后追加到文末。
- “更多”可切换文末追加、更换目标或替换正文。替换需要确认，并保留开头的 YAML 属性。
- 上下键选书，Enter 聚焦导入按钮，Ctrl/Cmd+Enter 导入；快捷键不能跳过确认。

同一次插件运行期间，向同一笔记重复导入同一本书时需要确认。**没有跨会话去重，也不做双向同步**，再次导入可能产生重复内容和块 ID。插件不修改远端备份；写入过程中关闭面板会等待完成。

### 书库显示

点击列表上方的排序按钮，按书名或备份修改时间升降序排列。默认按备份时间从新到旧，无有效日期的书籍排在最后。日期不是阅读或批注时间。

“显示书籍数量”限制列表展示，`0` 表示全部。搜索覆盖所有缓存书籍后再应用限制，不影响下载。书库显示和默认写入方式修改后立即保存。

## 模板

书库中的“调整模板”用于本次导入，点击“保存为默认模板”后可重复使用；默认模板也可在插件设置中编辑。

| 字段 | 内容 |
| --- | --- |
| `{bookName}` | 书名 |
| `{chapter}` | 章节索引 |
| `{highlightText}` | 高亮原文 |
| `{note}` | 个人批注 |
| `{color}` | RGB 十六进制颜色 |
| `{timestamp}` | UTC 时间 |
| `{id}` | 原始批注 ID |

模板支持 Markdown 和 HTML，字段值进行 HTML 转义，预览和导入使用同一模板。

## 数据与隐私

插件仅访问配置的 WebDAV 备份服务，没有遥测或额外联网服务。密码保存在 Obsidian Keychain，设置仅记录凭据名称；换设备时需重新配置密码。

书籍缓存以明文保存在插件目录，按服务器目录和账号隔离，可离线浏览。刷新失败时保留已有缓存；成功确认远端删除后，书籍从列表移除，已导入笔记不变。

## 常见问题

- **找不到书籍：** 确认所选目录包含 `.an` 文件，连接成功不代表备份目录正确。
- **认证失败：** 检查账号、应用密码和目录权限；密码不可用时选择其他 Keychain 或新建条目。
- **书籍更新失败：** 旧数据仍可使用，刷新即可重试；损坏或不完整的记录不会覆盖已有数据。
- **原笔记已变化：** 改为文末追加，或重新打开书库以记录新的光标位置。

遇到问题可提交 [GitHub Issue](https://github.com/seeyou2n1ght/obsidian-MoonReaderNoteSync/issues)。
