# MoonReader Note Sync

[English](README.md) | 中文

将静读天下（Moon+ Reader）WebDAV 备份中的高亮和批注导入 Obsidian，支持搜索书籍、预览笔记、自定义模板和离线浏览缓存。界面随 Obsidian 显示中文或英文。

需要 **Obsidian 1.13.0 或更新的桌面版本**，不支持移动端。版本变化见[更新记录](CHANGELOG.md)。

## 安装

### Obsidian 插件市场

1. 打开“设置 → 社区插件”，按需开启社区插件功能。
2. 点击“浏览”，搜索 **MoonReader Note Sync**。
3. 点击“安装”，然后“启用”。

后续可在社区插件设置中“检查更新”。

### 手动下载构建产物

1. 打开 [GitHub 最新发布](https://github.com/seeyou2n1ght/obsidian-MoonReaderNoteSync/releases/latest)，从 **Assets** 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 将三个文件直接放入笔记库的 `.obsidian/plugins/obsidian-moonreader-sync/`，目录不存在时自行创建。
3. 重启 Obsidian 或重新加载插件，在“设置 → 社区插件”中启用。

源码压缩包不是构建后的插件。更新时只替换上述三个文件，保留 `data.json` 和缓存文件，避免重复安装。

## 使用

### 连接备份

先在静读天下中开启 WebDAV 同步/备份阅读位置与批注，找到包含 `.an` 文件的目录（例如坚果云通常为 `https://dav.jianguoyun.com/dav/Books/.Notes/`，其中 `.Notes` 可能是隐藏目录，密码需使用坚果云**应用密码**而非登录密码）。

1. 在插件设置中填写“WebDAV 目录地址”和“账号”。
2. 从“已保存的 Keychain”选择条目，或点击“新建 Keychain”填写名称及密码或应用密码。
3. 可先“测试连接”，测试不会保存。点击“验证并保存连接”应用配置；新建条目时点击“创建 Keychain 并保存连接”。
4. 打开侧栏的书库按钮，或执行“浏览和导入笔记”命令。

Keychain 名称支持小写字母、数字和连字符，最多 64 字符，已有名称不会被覆盖。更换账号或服务器后需重新选择凭据。已有条目在 Obsidian Keychain 中管理。

#### 刷新与缓存机制

- 每次插件启动后，首次打开书库会先展示本地缓存，并在后台检查已配置的备份；再次打开沿用本次结果，需要重新检查时点击「刷新」或「重试」。
- 点击顶栏服务器名称可查看备份目录、上次检查时间和逐本失败原因；按 **Esc** 或点击外部区域可关闭浮层。
- 后台检查移除当前所选书籍时会清空导入选择，请重新选书；书单和批注无变化时只更新检查时间记录。
- 每次 WebDAV 请求超时时间为 30 秒，连接检查可取消。关闭设置会丢弃草稿并取消尚未开始写入的保存；已经开始写入时，保存及书库连接切换会继续完成。

### 导入笔记

在设置中可指定默认书籍排序和默认笔记排序，书库内切换排序也会保存为默认值。笔记可保留备份原序，或按章节与书内位置（`offset`，旧缓存缺少位置信息时沿用备份原序）、批注时间升降序排列；按时间排序时缺少时间的批注排在最后。

选择书籍后预览排序后的前 3 条批注，点击「查看全部」可展开完整预览，导入按钮写入该书的**全部批注**。固定顶栏可切换排序、收起至前 3 条或调整模板。更改排序或模板后，当前预览就绪即可写入。底部显示目标笔记和写入位置。

- 默认插入打开面板时记录的光标位置，不替换选中文本。焦点在其他面板时，使用仍打开的最近 Markdown 笔记。
- 没有打开的目标时，点击“选择笔记”，可直接选择已有 Markdown 文件或在选择器中新建笔记（默认以当前书名命名），再追加到文末。
- 点击底部目标路径可更换文件或新建笔记，旁边的写入方式菜单可选光标插入、文末追加或替换正文。窄窗口中可点「切换书籍」重新打开书单。替换需要确认，并保留开头的 YAML 属性。
- 上下键选书，Enter 聚焦导入按钮，Ctrl/Cmd+Enter 导入（焦点位于模板编辑框时不会触发）；快捷键不能跳过确认。

同一次插件运行期间，向同一笔记重复导入同一本书时需要确认。**没有跨会话去重，也不做双向同步**，再次导入可能产生重复内容和块 ID。插件不修改远端备份；写入过程中关闭面板会等待完成。

### 书库显示

点击列表上方的排序按钮，按书名或备份修改时间升降序排列。默认按备份时间从新到旧，无有效日期的书籍排在最后。日期不是阅读或批注时间。

“显示书籍数量”限制列表展示，`0` 表示全部。搜索覆盖所有缓存书籍后再应用限制，不影响下载。书库显示和默认写入方式修改后立即保存。

## 模板

书库中的“调整模板”用于本次导入，未保存的修改会在按钮上标出，可通过“恢复默认模板”撤销，或点击“保存为默认模板”持久化；默认模板也可在插件设置中编辑。

默认模板：

```markdown
> {highlightText} ^{id}
{#note}> <span style="color: {color}">{note}</span>
{/note}
```

| 字段 | 内容 |
| --- | --- |
| `{bookName}` | 书名 |
| `{chapter}` | 章节索引 |
| `{highlightText}` | 高亮原文 |
| `{note}` | 个人批注 |
| `{color}` | RGB 十六进制颜色 |
| `{timestamp}` | UTC 时间 |
| `{id}` | 原始批注 ID |

- **条件块：** 使用 `{#字段}...{/字段}`（如 `{#note}...{/note}`）包裹可选片段，仅在该字段非空时输出，避免纯高亮产生空白批注行。
- **换行与条目分隔：** 高亮与批注中的静读天下 `<BR>` 标记会自动转为换行（位于 Markdown 引用行内时保留 `>` 前缀，位于 `<span>` 等行内 HTML 标签内时转为 `<br>` 避免撕裂标签）。多条笔记拼接时，若前一条不以换行结尾且后一条不以换行开头，会自动补插空行（`\n\n`），防止 `>` 等块级语法与上一段正文粘连。
- **转义：** 模板支持 Markdown 和 HTML，字段值会进行 HTML 转义，预览和导入始终使用同一模板。

## 数据与隐私

插件仅访问配置的 WebDAV 备份服务，没有遥测或额外联网服务。密码保存在 Obsidian Keychain，设置仅记录凭据名称；换设备时需重新配置密码。

书籍缓存以明文保存在插件目录，按服务器目录和账号隔离，可离线浏览。刷新失败时保留已有缓存；成功确认远端删除后，书籍从列表移除，已导入笔记不变。

## 常见问题

- **找不到书籍：** 确认所选目录包含 `.an` 文件，连接成功不代表备份目录正确。
- **认证失败：** 检查账号、应用密码和目录权限；密码不可用时选择其他 Keychain 或新建条目。
- **书籍更新失败：** 旧数据仍可使用，刷新即可重试；损坏或不完整的记录不会覆盖已有数据。
- **原笔记已关闭或变化：** 改为文末追加，或打开目标笔记后重新打开书库以记录新的光标位置。

遇到问题可提交 [GitHub Issue](https://github.com/seeyou2n1ght/obsidian-MoonReaderNoteSync/issues)。
